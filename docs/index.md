# HealthLens Project Knowledge

**Status:** Phase 4 - Implementation  
**Last Updated:** 2026-05-20

HealthLens là nền tảng giúp người dùng Việt Nam chuyển đổi tài liệu/kết quả xét nghiệm y tế thành thông tin sức khỏe dễ hiểu, sử dụng OCR, lưu trữ hồ sơ sức khỏe, AI explanation, và family sharing network.

## Fast Paths

- For implementation context, start with [project-context.md](./project-context.md).
- For route changes, check [api-contracts.md](./api-contracts.md), `packages/shared/constants/api.ts`, and `apps/api/src/main/java/com/healthlens/api/constants/ApiRoutes.java`.
- For schema changes, check [data-models.md](./data-models.md) and add a new Flyway migration under `apps/api/src/main/resources/db/migration`.
- For async side effects, event publishing, OCR/email delivery, or package-boundary refactors, check [event-driven-architecture.md](./event-driven-architecture.md).
- For local setup, use [development-guide.md](./development-guide.md).
