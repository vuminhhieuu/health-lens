# Save Memory: Scribe

Sử dụng capability này để cập nhật bộ nhớ Sidecar của bạn.

## Các loại thông tin cần lưu:

- **Sở thích mới:** "Người dùng thích dùng emoji 🚀 cho các feature".
- **Quy tắc dự án:** "Scope `ui` nên được dùng cho các thay đổi trong thư mục `/src/components`".
- **Tiến độ:** "Đã hoàn thành tóm tắt cho Story 1-1".

## Hướng dẫn thực hiện:
1. Xác định file cần cập nhật trong thư mục bộ nhớ.
2. Sử dụng tool `replace_file_content` hoặc `multi_replace_file_content` để ghi nội dung.
3. Thông báo cho người dùng biết bạn đã ghi nhớ điều gì.
